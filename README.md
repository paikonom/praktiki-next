# Praktiki Next

Νέα έκδοση της εφαρμογής διαχείρισης Πρακτικής Άσκησης του ΕΚΠΑ.

Το project βρίσκεται ακόμη στη φάση καταγραφής απαιτήσεων και σχεδιασμού.
Δεν έχει επιλεγεί framework και δεν υπάρχει ακόμη εκτελέσιμη εφαρμογή.

Η υπάρχουσα εφαρμογή στο `../apps.praktiki.uoa.gr` λειτουργεί μόνο ως πηγή
για read-only μελέτη. Δεν τροποποιείται από αυτό το project.

## Αρχικές αρχές

- Σταδιακή και ελεγχόμενη μετάβαση, παράλληλα με την παλιά εφαρμογή.
- Καθαρός διαχωρισμός προσώπου, χρήστη και συμμετοχής σε πρακτική.
- Προκαθορισμένοι αλλά επεκτάσιμοι ρόλοι και πρόσβαση ανά τμήμα.
- Ιστορικό σημαντικών ενεργειών, υποβολών και αρχείων.
- Χειροκίνητη επιβεβαίωση για κρίσιμες εξωτερικές ενέργειες.
- Πλήρης μεταφορά των παλιών δεδομένων και αρχείων με ελέγχους ακεραιότητας.

Οι επιβεβαιωμένες απαιτήσεις καταγράφονται στο
[`docs/discovery.md`](docs/discovery.md).

Η προτεινόμενη σειρά υλοποίησης βρίσκεται στο
[`docs/roadmap.md`](docs/roadmap.md).

Η ασφαλής αντιστοίχιση και μεταφορά των παλιών PDF περιγράφεται στο
[`docs/file-migration-plan.md`](docs/file-migration-plan.md).
